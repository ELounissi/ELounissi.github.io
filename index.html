Open source

open-ml-notebooks

A free book of 86 executed Jupyter notebooks covering machine learning, deep learning and reinforcement learning, one method per notebook. Each chapter derives the maths, implements the method from scratch, then measures where it wins and where it loses on shared open datasets. No number appears in the text unless the notebook printed it.

Python · scikit-learn · PyTorch · MIT and CC BY 4.0

Computer-Vision

Shape descriptors worked through by hand: raw, central, normalised and Hu moments computed from images, with the invariances checked rather than assumed. Includes a dataset of one letter rendered at every angle through a full rotation, built so a descriptor claiming rotation invariance can be tested against 360 cases instead of an argument.

Python · Jupyter · image moments · shape analysis
